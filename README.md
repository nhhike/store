# NHHike Store

Welcome to NHHike Store! This is a Jekyll-based website for our hiking and outdoor store.

## Setup Instructions

1. **Make the repository public** in GitHub settings
2. **Enable GitHub Pages** in Settings → Pages and select `master` branch as source
3. **Configure your domain** - Update DNS records to point nhhike.com to GitHub Pages
4. **Wait for deployment** - Your site will be live at https://nhhike.com

## Customization

- Edit `index.html` to customize the front page content
- Modify `_config.yml` to change site settings
- Add new pages in the root directory or create a `_pages` folder
- Style with CSS by creating a `_sass` folder
